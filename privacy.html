Iron Front - Privacy Policy

Iron Front collects no personal data.

  • No account or login is needed. There is no advertising and no cross-site tracking.
  • Crash and error reports: when you play the web version, if the game hits an error it sends an anonymous diagnostic report to Sentry so we can fix bugs. A report contains the error message and code location, the game version, the browser and operating system type, and game context such as the mode (skirmish, endless, online) and map. It contains no name, account, email, IP-based identity, chat, replay or saved maps, and no personal data. The game sends no reports when opened from a local file or offline, and it keeps working normally if the reports are blocked.
  • Gameplay statistics: the web version also sends a few anonymous gameplay events to PostHog so we can see which modes, maps and difficulties are played and balance the game: when the main menu opens, when a match starts (mode, map, AI difficulty, faction, number of players), when it ends (win, loss or quit, and how long it lasted) and whether an online connection succeeded (direct or relay). Each event carries the game version and a random ID stored in your browser's local storage. There are no accounts or profiles, no IP address is kept, and there is no click tracking, screen recording, name, chat, room code or saved map. Nothing is sent from a local file, offline, in the App Store app, or when your browser's Do Not Track or Global Privacy Control setting is on. Clearing site data resets the random ID.
  • Settings, local high scores and saved replays are stored only on your device (browser local storage). Uninstalling the app or clearing site data removes them.
  • Online play is optional and peer-to-peer (WebRTC). Players join with a room code. Game commands go directly between the players' devices. Public signalling relays are used only to connect the players, and no game data is stored on a server.
  • Replays are saved only when you press "Save replay", and they stay on your device unless you choose to share the file.

Third-party code: three.js (MIT licence) and Trystero (MIT licence). All sound is synthesised on the device.

Questions or support: open an issue at github.com/IronForgeCreateGM/iron-front/issues.
